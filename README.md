# Student Utils — TDD & Debugging Lab

This repository demonstrates the **RED -> FIX -> GREEN** testing cycle using Python's `unittest` framework to debug and verify student evaluation utilities.

## Files
- `student_utils.py`: Core utility functions for calculating mark averages, checking pass boundaries, and evaluating final grades.
- `test_student_utils.py`: Unit test suite containing 9 test cases verifying boundaries and expected outputs.
- `bug_notes.md`: Detailed breakdown of each defect, failing behavior, root cause, and resolution.
- `audit.md`: Post-fix quality and edge-case assessment.

## How to Run the Tests
Run the test suite directly with Python:
```bash
python test_student_utils.py
